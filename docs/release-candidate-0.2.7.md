# v0.2.7 安装修复 RC

记录日期：2026-10-31（UTC+8）。

- 远程入口改用简短的 `bash <(curl -fsSL 固定版本URL) --rc`；双机向导生成的命令继续固定源码提交。
- `--rc` 选择引导脚本对应版本并允许测试发行；不改变默认仅选择正式 Release 的行为。
- 首次缺少 jq 时先刷新 APT 索引，再按需安装；任一源刷新失败即停止，不进行整机升级、不删除锁或替换软件源。
- 平台检测恢复接受 Debian 12 及点版本，继续要求 amd64、运行中的 systemd、隔离能力和 IPv6 双栈。
- 简短入口依赖 GitHub HTTPS，不再额外校验引导脚本摘要；完整包仍校验清单、SHA256、大小、源码版本和目录结构。

本版仅包含安装修复；未收录工作区另行开发的核心版本选择改动。旧 v0.2.6 标签和发行包保持原样。

本地证据：APT/HTTP 替身覆盖索引更新先于安装、更新失败停止、安装失败停止和已有 jq 跳过 APT；命令生成检查两种来源；平台样本、Bash 语法、文档及 ShellCheck 检查通过。Windows 无 Linux/systemd 环境，不能代替 Debian 12 VPS 的安装、服务重启、整机恢复或真实网络验收。实机验收仍待完成。
