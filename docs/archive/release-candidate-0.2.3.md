## C：日常持续运行

观察周期应覆盖用户实际工作时段、空闲后恢复、普通网页、长连接与下载；时长由实际使用安排确定，不把任意天数当作安全认证。本页不创建后台任务或定时自动化。

- 从systemd cgroup及可执行路径定位真正的Xray进程；MainPID可能是shell，不能把包装进程的CPU／RSS当作核心数据。
- 采集时间、实际核心PID／版本、CPU时间增量、RSS、FD数量、连接数量、异常退出和恢复时间。每种计数明确范围；缺少采样为“未采集”，不是0。
- 结合负载变化判断FD／连接是否异常增长，区分累积量、瞬时量和稳定空闲值。保留中断、手动重连和测试站故障，不能只存成功样本。
- 性能只沿设备→VMISS→诺亚方向测量；不把诺亚当本地测速客户端。用户报告约18 MB/s作为使用反馈，不是本轮独立测量，也不要求标称200 Mbps每次跑满。
