# 1.1.0 正式版

发布日期：2026-11-01（UTC+8）。1.1.0 将 0.2.10 开发阶段已经验收的功能整理为正式发行，协议字段与路由模型保持。

- 默认 REALITY 目标 archive.archlinux.org；核心默认跟随最新（含 Pre），菜单 6 → 5 可切换为仅正式版。项目脚本的正式/实验发行与 Xray 核心更新跟随是独立设置。
- 加固 systemd、已知旧 unit 的事务迁移、BBR 可选管理、撤回核心版本拒绝、HTTP/SOCKS5 导出和 UDP/443 本地阻断。
- 菜单 8 和 self update --channel stable|pre 支持脚本稳定/测试双向切换；默认通道来自当前已验证的脚本 Release 来源，失败保留原脚本和通道，独立于 Xray 核心 track。
- 无参在线引导精确选择该入口版本的正式 Release；即使日后发布更高版本，v1.1.0/install.sh 仍解析 v1.1.0。--script-version 和兼容 --rc 仍可显式选择其他发行模式；离线源码和固定提交入口保持。
- 发行资产包括源码包、SHA256、manifest.json 和引导脚本摘要；GitHub Actions 生成构建来源证明。默认在线安装只接受对应正式版；self update 按当前已验证来源或显式 stable/pre 通道选择，始终拒绝草稿。
- GPL-3.0-only。当前源码和文档使用通用节点代号；提交身份使用 GitHub noreply。可写历史分支、标签和旧 RC 源码资产同步清理；旧 PR、GitHub 缓存及其他人的克隆仍可能保留旧对象，不能宣称这些副本已删除。

验证基线：两个官方核心各 38 项真实协议检查；Debian 12/13 引导矩阵；真实临时 systemd 门禁及加固主进程启动/重启。节点C的 Debian 12 实测完成 9 项验收、30 TCP + 2 UDP 门禁、BBR 接管/恢复及 16 次独立 Windows HTTPS 请求，见[实测记录](../live-verification-0.2.10.md)。这些是此前开发阶段的实际记录，不改写成已经在所有系统或网络验证。

本版新增的发行入口与未来版本兼容回归、隐私扫描、完整 CI、公开发行资产及来源证明验证均已通过。节点C通过真实 Release 完成脚本 pre → stable → pre → stable，两个通道的无参跟随更新也通过；每步保持完整节点状态、配置、unit 与 PID，旧身份外部 HTTPS 请求 8 次成功，最终为 1.1.0 稳定版，见[发行与切换实测](../live-verification-1.1.0.md)。

跨版本生产核心回滚、Debian 13 完整 systemd 安装/卸载生命周期、BBR 从未加载模块状态及整机重启持久化仍不在已有证据范围。
