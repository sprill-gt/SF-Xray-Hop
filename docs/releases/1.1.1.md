# 1.1.1 正式版

日期：2026-11-01（UTC+8）。本版包含投产前静态审查后的修正，保持现有严格出口确认策略、BBR 默认关闭和脚本更新不重启运行核心的行为。

- 自动选版跳过撤回版本时提示继续查找候选；明确指定撤回版本仍拒绝。
- 撤回策略读取失败立即停止自动选版，不将策略错误当成普通候选跳过。
- BBR status 提示运行值偏离和重启持久化未验证，不执行 sysctl --system；接管原已启用 BBR 的主机时说明 off 恢复的是接管时原值。
- 发行工作流按 tag 读取对应版本说明，缺少文档时保留 CHANGELOG 指引。
- 引导脚本、管理脚本与 README 固定入口同步为 1.1.1；脚本发行通道为 stable。

本地选版、BBR 隔离回归及静态检查已通过；这些测试模拟网络、服务和 sysctl，不是生产部署验收。Linux CI 以本版提交对应的工作流结果为准。

已知边界：旧 unit 迁移后加固在下次明确重启生效；成功更新后的备份不会覆盖后续配置事务，仍需维护窗口验证。BBR 尚未完成整机重启持久化验证。没有新增 Debian 13 完整 systemd 生命周期、多客户端长时间负载或公网设备实测。详见[审查复核](../review-response-20261101.md)。
