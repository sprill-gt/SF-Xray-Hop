# v0.2.5 发布候选与 Debian 13 验收

记录日期：2026-10-01（UTC+8）。用户已将两台 VPS 重装为 Debian 13，并要求重新测试、准备正式版。用途固定：**设备 → VMISS 中转／入口 → 诺亚落地／出口 → Internet**。

## 候选范围

仅声明 Debian 13 和 Ubuntu 24.04.3 LTS、amd64 支持；Debian 12 和 Ubuntu 22.04 不再纳入当前支持。0.2.4 的公开包、标签及历史测试记录保留不变。0.2.5 不变更协议、服务模型或核心安全门槛；收窄平台检测，并让独立客户端测试逐请求记录序号、时间和 curl 结果，避免只知道某批失败。

两台 SSH 实测环境：VMISS Debian 13.3，诺亚 Debian 13.7；均为 amd64／systemd，初始没有本项目命令或运行中的 Xray。Ubuntu 24.04.3 的实机证据来自0.2.4，不冒充本次新包部署结果。本轮已使用实际公开候选包完成下列生命周期操作；固定资产摘要、逐项结果和失败记录见[Debian 13 实机验收](vps-lifecycle-0.2.5-2026-10-01.md)。

## 晋级原则

用户确认本阶段停止追加重复故障测试，进入日常试用 RC，后续客户端体验由用户验收。已完成的生命周期和未完成的 GUI／长期观察仍分别报告；不为转正另设压力测试或固定时长要求。当前交付为增加脚本版本入口的 [v0.2.6 RC](release-candidate-0.2.6.md)，本文件保留 0.2.5 的实际测试范围。

0.2.4 的出口重启后首批 TLS 错误在 Debian 13 仍有复现，当前已记录到批内第一请求。1-RTT 对比仍有首次超时，暂不把票据机制认定为唯一根因或修改默认值。常驻客户端与 VMISS 进程不重启时六次均恢复；这不代表中断中的应用请求无损。私密备份、完整分享链接和配置只保存在受限测试目录，不进入 Git 或公开记录。
