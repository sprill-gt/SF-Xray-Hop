# v0.2.5 发布候选与 Debian 13 验收

记录日期：2026-10-01（UTC+8）。用户已将两台 VPS 重装为 Debian 13，并要求重新测试、准备正式版。用途固定：**设备 → VMISS 中转／入口 → 诺亚落地／出口 → Internet**。

## 候选范围

仅声明 Debian 13 和 Ubuntu 24.04.3 LTS、amd64 支持；Debian 12 和 Ubuntu 22.04 不再纳入当前支持。0.2.4 的公开包、标签及历史测试记录保留不变。0.2.5 不变更协议、服务模型或核心安全门槛；收窄平台检测，并让独立客户端测试逐请求记录序号、时间和 curl 结果，避免只知道某批失败。

两台 SSH 实测环境：VMISS Debian 13.3，诺亚 Debian 13.7；均为 amd64／systemd，初始没有本项目命令或运行中的 Xray。Ubuntu 24.04.3 的实机证据来自0.2.4，不冒充本次新包部署结果。验收必须下载实际公开候选包，核对来源与摘要，不能用本地源码替代。

## 晋级原则

候选包生命周期通过后仍分别报告 GUI 和日常持续运行的结果。不会仅凭 Debian 系统较新、源码回归通过或一次 HTTPS 成功便宣布正式稳定。双机不要求重新跑已退出支持范围的系统或原三系统 3×3 矩阵；未测配对和客户端行为不作承诺。

0.2.4 的出口重启后首批 TLS 错误保留为待调查项。新测试必须保留失败请求及重试数据，区分请求恢复、客户端进程重启、入口手工重启，不以重试成功抹去原始失败。私密备份、完整分享链接和配置只保存在受限测试目录，不进入 Git 或公开记录。
